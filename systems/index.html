시스템 한눈에

게임 화면과 공식 게임 가이드에서 확인한 시스템을 짧게 정리했어요. 새로 확인되는 수치는 바로 더해 가요.

지역 12곳 · 순찰과 평정

  • 업적에 나오는 사냥 지역: 윈스톤 · 킨바이 · 노튼 · 라인하르트 · 알테스 · 벨두인 · 엑카루 · 레이단 · 수아즈 협곡 · 레베카 · 크라임숲 · 지브라
  • 지역마다 ○○ 순찰(몬스터 1,000~2,000마리)과 ○○ 평정(200,000마리) 업적이 있어요
  • 던전: 야탄 신전(1실부터) · 골렘의 미궁(층 구조) — 둘 다 전용 시간 충전석으로 시간 추가
  • → 업적 목록에서 단계별 목표 보기

보스 · 메인 퀘스트 이정표

  • 서릿빛 오크 족장 — 메인 [2-15. 부활한 자] (칭호 설원의 지배자)
  • 만티코어(유적의 수호자) — 메인 [4-22. 눈을 뜨다]
  • 엘핀스톤(13번째 도시의 주인) — 메인 [5-16]
  • 교황 드레비고 — 메인 [8-18. 축복인가 저주인가]
  • 보스 이름이 붙은 유니크 제작템: 말락서스의 망토 · 만티코어의 각반 · 서릿빛 오크 족장의 투구 · 어스름 오크 족장의 신발 (보스 전용 재료 필요)

스킨 · 수집 효과

  • 메뉴 스킨 탭: 외형 · 액세서리 · 펫 · 효과
  • 외형 · 액세서리 · 펫 스킨을 모을수록 수집 효과가 쌓여요 (효과 탭에서 개수 확인)
  • 스킨마다 보유 효과가 따로 있어요. 예: 모르페우스의 마스크 = 치명타 1%
  • 세트로 모으면 세트 효과도: 예) 미완의 시절 세트 = 경험치 획득량 1%

잠재력

  • 메인 메뉴 잠재력: 여러 보드로 나뉘고 캐릭터 레벨에 따라 차례로 열려요
  • 열면 초급 · 중급 · 상급 중 하나가 붙고, 재료로 다시 돌릴 수 있어요 (자동 변경으로 목표 등급·능력치까지 반복)
  • 묶음(결속) 등급은 그 안에서 가장 낮은 잠재력 기준. 초급·상급·상급이면 결속은 초급
  • 보드마다 상급 개수로 달성 효과가 올라요. 다른 보드와 합산되지 않음
  • 중급 이상 설정 = 재료 + 다이아로 초급만 빼 주는 기능이지 상급 확정이 아니에요 (방송 화면 기준 변경 1번에 다이아 100)
  • 재료는 인벤토리에 있어야 해요. 창고에 둔 재료는 못 씀

갓 핸드 확정 · 합성

  • 유니크 이상이 나오면 바로 안 들어오고 확정 탭에서 대기
  • 다이아로 같은 등급 안에서 최대 5번 재소환, 나왔던 것 중 하나를 골라 확정 (대기 시간이 지나면 확정만 가능)
  • 이미 있는 갓 핸드가 또 나오면 등급별 포인트로 바뀌고, 포인트로 합성
  • 에픽 이상 합성에 실패하면 상위 등급 마일리지가 쌓이고 15개면 상위 등급 확정
  • 처음 얻는 갓 핸드마다 마스터리 포인트. 마스터리 효과는 언제든 바꾸고 프리셋별 저장 가능

오버기어드 이용 팁

  • 퀘스트 「잊혀진 영웅」을 끝내야 열려요
  • 장비를 낀 슬롯에만 효과. 빈 슬롯은 강화해도 소용없음
  • 장비를 바꿔도 슬롯 성장치는 그대로 남아요
  • 상한에 닿으면 돌파, 재료는 등급별 혼의 그릇
  • 자동 강화로 다음 레벨까지 한 번에
  • 코어 점수는 슬롯 강화 · 돌파 + 장비 등급 · 티어 · 시그니처 여부 + 장비 강화 · 연금 · 감정으로 쌓여요. 장비를 바꿔 점수가 내려가면 오버클럭이 다시 잠길 수 있어요

연금 · 감정

  • 연금: 촉매제 1개 + 골드로 모든 기본 슬롯을 한꺼번에 다시 굴려요. 한 줄만 고정하는 기능 없음
  • 상위 등급 장비는 모든 슬롯이 최대치면 보너스 능력치 추가
  • 축복받은 연금 촉매제는 수치를 최대로 주지만 종류는 무작위
  • 자동 연금: 슬롯마다 원하는 능력치를 정해 두면 맞을 때 멈춤 (한 슬롯만 맞아도 · 최대 수치일 때만 멈추게 설정 가능). 원하는 옵션이 평균 몇 번 걸리는지는 연금 옵션 계산기
  • 연금 능력치는 강화 · 감정 후에도 유지
  • 감정은 에픽 이상만. 일반 감정은 실패해도 장비 유지 / 고급 감정은 실패 없음, 대성공 = 전설적인 감정(이후 추가 감정 불가)
  • 감정 비용(게임 화면 11/27): 100만 골드 + 플라리안의 눈 1개, 일반 감정 성공 확률 20%. 예: 에픽 허리띠 감정 성공 → 고정 피해 감소 4 · 코어 점수 +10

강화 주의사항 (공식)

  • 결과는 상승 · 유지 · 하락 · 초기화 · 파괴 중 하나
  • 다중 강화에는 저주 강화석과 파괴 보호권을 못 써요
  • 파괴 보호권은 성공률을 올리지 않고, 결과와 상관없이 소모, 보호도 확률
  • 다중 강화 화면의 재료 수량은 전부 성공했을 때 기준 최대치

던전 이용 시간

  • 기본 시간(던전별 초기화) + 충전 시간(던전 전용 시간 충전석, 초기화돼도 남음)
  • 안에 있으면 싸우지 않아도 시간이 줄어요
  • 목록의 안전 · 일반 · 위험 = 다른 플레이어 공격 가능 여부
  • 퇴장 버튼은 들어가기 전 자리로, 귀환 주문서는 마을로

왕실 무기고 납품 규칙

  • +6 이상 강화한 무기 · 보조 장비 · 방어구 · 장신구만 납품
  • 장착 중이거나 잠금한 장비는 목록에서 빠짐. 아끼는 장비는 잠가 두세요
  • 실패하면 코인 대신 템빨 코인 조각
  • 주간 보너스 품목은 성공 시에만 배율 추가, 개수 제한 있음
  • 차원 납품 레벨 보상은 단계별로 계정당 1번. 이주하기 전에 받을 것 받아 두기

차원 시즌 · 이동

  • 퀘스트 「차원: 마지막 관측」 완료 후 다른 차원으로 이동
  • 이동 비용 + 체류 시간이 필요하고, 체류 시간이 끝나면 자동으로 소속 차원 복귀
  • 시즌 없음 → 튜토리얼 시즌 → 프리 시즌과 정규 시즌 반복
  • 프리 시즌엔 공헌도가 안 쌓임 / 정규 시즌 끝나면 디비전 1위 승격 · 꼴찌 강등
  • 시즌 보상: 공헌도 순위별 작위 + 정규 시즌부터 차원 세금(다이아)

보스 알림 · 기여도

  • 보스 목록의 종 아이콘으로 출현 알림 켜기
  • 알림은 나타난 순간에만. 미리 알려 주지 않아요 → 사이트 보스 타이머로 주기 기록
  • 알림 설정은 기기마다 따로 저장 (PC·폰 각각 켜기)
  • 보상은 피해량 기여도 기준. 일부 보상은 최소 피해를 넘겨야 받음

비접속 모드 · 스케줄 모드

  • 비접속 모드는 Lv.30부터, 캐릭터마다 하루 12시간 (매일 초기화)
  • 다른 차원에 있거나 무기가 손상되면 실행 안 됨
  • 스케줄 모드는 Lv.35부터. 함께 켜면 정해 둔 사냥터·던전으로 알아서 이동
  • 끝나면 진행 시간, 얻은 경험치·골드·아이템을 확인할 수 있어요

사망 페널티

  • 죽으면 다음 레벨까지 필요한 경험치의 5%가 깎여요. 모자라면 레벨이 내려갈 수도
  • 장착 중인 무기·방어구·장신구·곡괭이·유물 일부가 손상 → 능력치가 안 붙고 거래·강화·분해 불가
  • 무기가 파손되면 공격 자체가 안 돼요
  • 낮은 레벨 보호 구간과 페널티 없는 지역은 예외, 복구 기능으로 되돌릴 수 있어요

거래소

  • Lv.32부터 이용, 구매는 다이아
  • 판매 등록 때 골드 수수료가 바로 빠지고, 팔리면 수수료 뺀 금액 정산
  • 여러 개 팔 땐 개당 가격이 아니라 총액을 입력해요. 0 하나 실수 주의
  • 일괄 구매: 최저가 10개 자동 선택
  • 다른 차원에 가 있으면 그 차원 거래소에서 구매만 가능

오버기어드 (강화)

  • 장비가 아니라 부위별 슬롯을 강화해 능력치를 올림
  • 강화 상한에 닿으면 돌파로 최대 레벨 확장
  • 돌파 수준에 따라 그 부위 장비 능력치가 일정 비율 증가
  • 조건을 채우면 장비에 봉인된 추가 능력치 해금

파브라늄

  • 핵심 강화 재료
  • 안 쓰는 장비 분해, 또는 강화 실패 시 획득
  • 장비 제작과 무기 개조에도 사용

코어 점수 · 오버클럭

  • 장비 등급·강화·돌파·연금·감정이 코어 점수에 반영
  • 일정 점수에 도달하면 오버클럭 해금
  • 전투 중 게이지를 채워 강력한 추가 버프 발동
  • 총 코어 점수 보상(게임 화면 11/27): 270 일반 방어력 3 → 320 치명타 피해 감소 1.5% → 370 스킬 회피 3 → 420 스킬 쿨타임 감소 1.5% → 480 PVE 공격력 3 → 540 골드 획득량 2% → 600 경험치 획득량 2% → 660 스킬 방어력 4 → 720 일반 방어력 4 → 800 PVE 방어력 4 → 880 오버클럭 Lv.2 해금 → 960 치명타 피해 2.5% → 1,040 마법 방어력 5 … → 1,500 골드 획득량 2.5% → 1,600 경험치 획득량 2.5% → 1,700 고정 피해 5 → 1,800 회피 5 → 1,900 최대 물약 소지량 50 → 2,000 디버프 저항 2.5% → 2,100 PVE 고정 피해 5 → 2,200 최대 HP 100 → 2,300 PVP 피해 감소 무시 5 … 8,500점 오버클럭 Lv.5까지 70단계 → 전체 표 · 다음 보상 계산
  • 슬롯 강화 1번 = 골드 1,000 + 칠흑성의 파브라늄(귀속), 성공하면 코어 점수가 오르고 슬롯 효과(예: PVE 명중)가 붙어요. [+1 자동 강화] 체크 가능

시그니처 장비

  • 장비 제작 대성공 시 획득
  • 제작자 이름과 장인 등급이 새겨지고 다른 이용자도 확인 가능
  • 안전 강화 단계가 일반 장비보다 2단계 높음
  • 코어 점수 추가 상승

갓 핸드 메모리

  • 원작에서 그리드만 쓰던 갓 핸드를 모두가 사용
  • 공격형·방어형·보조형 슬롯에 하나씩 장착
  • 공격형은 적중 시, 방어형은 피격 시, 보조형은 스킬 사용 시 발동
  • 조합을 프리셋으로 저장해 사냥·PvP 전환

차원 (서버)

  • 서버 하나가 하나의 차원
  • 소속 서버를 유지한 채 다른 서버와 협력·경쟁
  • 이주로 소속 변경, 차원 간 이동은 거리별 비용·페널티
  • 신규 서버는 일정 기간 보호 그룹

차원 리그 · 작위

  • 서버 공헌도 합산 성적으로 상·중·하 디비전
  • 시즌 동안 쌓인 세금(다이아)을 공헌한 이용자에게 분배
  • 개인 공헌도로 공작부터 남작까지 작위
  • 후작 이상은 파티 버프 액티브 스킬

장비 강화 (장비 성장)

  • 메뉴 장비 성장: 강화 · 연금 · 감정 / 대상은 무기 · 방어구 · 장신구 · 특수
  • 단일 강화와 여러 장비를 한 번에 올리는 다중 강화가 있음
  • 무기는 무기 강화석 1개 + 골드. 실측 +0→+1: 성공 100%, 1,000 골드, 무기 최소/최대 공격력 각 +1
  • 강화 1번 골드는 단계와 상관없이 등급으로 정해져요: 노멀 1,000 · 레어 1,500 · 에픽 2,000 · 유니크 3,000 · 레전드리 무기 5,000 (무기 · 방어구 · 장신구 같음). 예: 에픽을 +5→+12까지 노리면 시도 횟수 × 2,000골드
  • 안전 강화 구간이 표시되고, 화면의 +4 · +5 버튼으로 목표 단계까지 바로 올릴 수 있음 (훈련용 대검은 안전 +5)
  • 안전 구간을 넘기면 실패 시 파괴 위험 → 파괴 보호권을 등록해 막을 수 있음
  • 시그니처 장비는 안전 구간이 2단계 더 넓음
  • 단계별 확률·비용은 강화 기록기에 남겨 두면 계산기에서 바로 쓸 수 있어요

펫

무기 스킬 · 스킬북

  • 스킬북 값 예시 — 대검(레이단 스킬 상인, 11/27 방송): 올려치기 1,500 · 대검 수련 5,000 · 찌르기 30,000 · 돌진 공격 250만(Lv.56) · 전투의 함성(Lv.63)
  • 무기 스킬 예시: 지팡이 마력탄(노멀, 공격력 190%, MP 8, 8.4초) · 회복탄(에픽, 312% + 준 피해의 5% MP 회복, MP 29, 13.4초) · 지팡이 수련(노멀 버프, 300초 무기 최대 공격력 +2 · 최소 +1) / 활 +2 강화 화살(노멀, 142%) / 대검 강철 의지(에픽 버프, 300초 방어력 +30, MP 98)
  • 자동 사용 주기를 정하면 스킬 창 아래에 「10초당 평균 MP 회복량 · 소모량」이 떠요. 소모량이 회복량보다 크면 자동사냥 중 MP가 바닥나니 주기를 늘리거나 MP 회복을 올리세요

클래스 스킬 구조

  • 스킬 창에 어느 클래스 스킬인지 빨간 글씨로 표시돼요
  • 유니크 클래스는 에픽 클래스 하나의 스킬 3개를 물려받아요 (유니크 2 + 에픽 3 = 5개). 활 확인분: 화염사수 → 홍염의 화살 · 마물사냥꾼 → 드비리온의 사자 · 윈드 워커 → 폭풍사수 · 명사수 → 신궁 · 레인저 → 저격수 · 정예 궁사 → 특등 사수 / 대검: 정예 전사 → 근위 기사
  • 그래서 에픽 활은 최소 6종(명사수 · 정예 궁사 · 화염사수 · 마물사냥꾼 · 윈드 워커 · 레인저)
  • 레전드리는 스킬 9개, 유니크 5개, 에픽 3개, 레어 0개
  • 그래서 상위 클래스를 노릴 땐 같은 계열 에픽(화염사수 → 홍염의 화살) 스킬이 어떻게 쓰이는지 먼저 익혀 두면 좋아요
  • 공속 · 시전 속도: 레어 16 · 7% → 에픽 28 · 15% → 유니크 43 · 27% → 레전드리 60 · 40% → 초월자 70 · 50%

클래스 도감 · 수집 효과

  • 클래스 메뉴 → [도감]. 등급별 수집 칸: 노멀 24 · 레어 24 · 에픽 24 · 유니크 24 · 레전드리 4 = 전체 100종 (방송 화면, 11/26)
  • 클래스를 모을수록 오른쪽 「획득 효과」가 쌓여요. 100% 완성 시 화면에 보인 값: 무기 최대 공격력 2 · PVP 공격력 25 · 일반 방어력 29 · 스킬 방어력 26 · PVE 방어력 8 · PVP 방어력 9 · 원거리 방어력 5 · 마법 방어력 2 · PVE 방어력 무시 3 · PVP 명중 4
  • 회피: 근거리 4 · 원거리 2 · 마법 5 · PVE 2 · PVP 1 · 회피 1 / 주는 피해 증가율 1.5% · 일반 피해 증가율 1.5% · 받는 피해 감소율 1% · 일반 피해 감소율 1%
  • 안 쓰는 클래스도 갖고만 있으면 효과가 켜져요. 그래서 중복 클래스는 합성 포인트로 돌리되, 아직 없는 클래스는 한 번씩 모아 두는 게 이득
  • 도감 왼쪽에 「수집 효과」 · 「성장 효과」 두 탭이 있어요 (성장 효과 내용은 방송에 아직 안 나와 확인 중)

초월자 (최종 클래스)

  • 클래스 메뉴 초월자 탭: 레전드리 클래스 4종(대검 · 활 · 지팡이 · 바이블 하나씩)의 힘을 융합해 개방
  • 능력치 근력·민첩·지력·체력 각 90 · 공격 속도 70% · 시전 속도 50% · HP 5,000 · MP 1,000 · 상태이상 적중/저항 각 5%
  • 비교: 레전드리 서사시의 마검사 HP 2,025 · 공속 60% / 에픽 HP 725~775 · 공속 28% / 레어 HP 200~250 · 공속 16%

  • 레전드리끼리 비교: HP 마검사 2,025 > 궁성 1,950 > 교황 1,875 / MP 교황 500 > 궁성 425 > 마검사 350, 공속 60% · 시전 40%는 같음
  • 여는 법 (공식): 클래스 → [초월자] 탭에서 필요한 레전드리 4종 보유 현황 확인 → 4종을 다 가지면 [개방] 버튼 → 같은 화면 [전직]
  • 최초의 초월자: 11/26 밤 뜨뜨뜨뜨의 「그리뜨뜨」(레가스 서버) — 넥슨이 공식 이벤트로 축하했어요(접속 선물 12/1까지)
  • 실제 화면 (뜨뜨뜨뜨 방송, 11/26 밤): 레전드리 4종을 다 모은 뒤 [개방]을 누르면 컷신이 나오고, 4종 초상화 아래 자물쇠 4칸이 무기 계열 4칸(대검 · 활 · 지팡이 · 바이블)으로 바뀌며 버튼이 [전직]으로 바뀌어요. 레벨 48 캐릭터로 개방 확인
  • 전직하면 지금 낀 무기 계열로 시작. 클래스 초상화 아래 톱니로 무기 계열마다 프리셋(장착 무기 · 스킬 퀵슬롯 · 소모품) 하나씩 저장

  • 계열을 바꿔도 이전 계열 액티브 버프는 남은 시간 동안 유지(패시브는 아님). 일반 클래스 ↔ 초월자 전직은 버프가 지워져요

클래스 성장 (각인)

  • 캐릭터 1 · 2 · 3차 각성을 하면 각각 에픽 · 유니크 · 레전드리 클래스 성장이 열려요 (각성 Lv.50 · 75 · 90)
  • 클래스 → 에픽 이상 클래스 선택 → [성장]: 클래스마다 각인 슬롯 6개, 슬롯마다 정해진 아이템을 넣으면 그 단계 효과(스탯 · 스킬 레벨) 획득
  • 각인 효과는 그 클래스로 전직했을 때만 적용. 일괄 각인 가능
  • 각인한 아이템은 되돌릴 수 없어요 — 넣기 전에 아이템 확인
  • 클래스를 처음 얻을 때마다 등급별 수집 효과, 에픽 이상은 누적 각인 수에 따라 추가 효과 (같은 서버 계정 공유)

공격대 (최대 50명)

  • 최대 10파티 · 50명. 메뉴 → [파티/공격대]에서 생성. 일반 공격대(누구나) / 길드 공격대(같은 길드만) — 만든 뒤 유형 변경 불가
  • 모집: 서버 · 지역 · 길드 채팅에 모집 글 → 공격대 목록에도 뜸. 목록의 [참여]는 확인 없이 바로 참여(레벨 조건 필요), 직접 초대는 레벨 조건 무시
  • 각 파티 첫 칸이 파티장. 공격대장이 분배 방식(순차 · 무작위 · 기여도 · 자유)을 정하면 모든 파티에 적용. 길드 공격대는 일정 등급 이상 아이템이 길드 보관함으로
  • 경험치 · 골드는 공격대가 아니라 원래 파티 분배 방식대로
  • 차원 이동 · 뱀파이어 던전 입장 시 공격대에서 자동 탈퇴. 공격대장이 나가면 다음 순번에게 자동 위임

모험단 · 길드 승격

  • 모험단 → 길드 2단계. 메인 메뉴 왼쪽 [길드]에서 가입 · 관리. 모험단은 전용 채팅 · 구성원 관리, 길드가 되면 길드 보관함 · 길드 공격대 · 우호/적대 설정이 열려요. 모험단 때 쌓은 활동 포인트 · 채팅 · 공지는 그대로
  • 가입 방식: 즉시 · 승인 · 암호. 한 곳에만 소속 가능하고, 옮기려면 먼저 탈퇴(탈퇴 · 추방 후 한동안 재가입 제한)
  • 승격 순서: 모험단장이 라인하르트 성 길드 관리자 NPC에게 심사 신청 → 서명 + 템빨 코인 모금 → 최종 서약
  • 11/27 점검 후 조건: 심사 신청 템빨 코인 500(전 2,000) · 모금액 3,000(전 10,000) · 서명 3명(전 10명) · 승격 후 기본 정원 30명(전 20명). 심사 신청에 쓴 코인은 돌려받을 수 없어요
  • 서명은 응원이 아니라 승격되면 그 길드에 자동 가입되는 절차. 어디에도 소속 안 된 캐릭터만, 한 모험단에만 서명 가능(승격 전 철회 가능)
  • 활동 포인트: 인사 버튼 · 하루 첫 채팅 · 몬스터 처치 · 퀘스트/업적 · 길드 채팅 알림에 이모지 반응(정해진 시간 안). 길드 레벨이 오르면 최대 인원 · 깃발 꾸미기 확장
  • 길드 랭킹(주간 활동 포인트, 매주 월 오전 5시 초기화) 순위에 따라 거래소 판매 세금 감면
  • 보관함: 길드 공격대 전리품이 모여요. 권한자가 직접 나누거나 거래소에 팔아 대금을 나눔(우편함으로 받음). 보관함에 물건 · 재화가 남아 있거나 정산 중이면 해산 불가

파티 (최대 5명)

  • 최대 5명, 한 파티에만. 파티 버튼 → [파티 생성]. 초대는 이름 검색 · 주변 이용자 · 접속 중 길드원
  • 파티 홍보: 목적(자유 · 사냥 · 보스) + 채널(지역 · 서버 · 길드)을 고르면 채팅에 참여 링크가 올라가요. 보스 · 엘리트를 대상으로 찍으면 빠른 파티 생성 알림
  • 자동 전투 2가지: 파티장 타겟(따라다니며 같은 대상 공격, 내 매너 모드 무시) / 파티장 주변(멀어지면 파티장 쪽으로 복귀)
  • 분배: 순차 · 무작위 · 기여도 · 자유. 경험치 · 골드는 가까이 있는 파티원끼리 나누고, 레벨 차이가 크면 줄어요
  • 파티 효과 수치(게임 화면): 4인 보스 피해 증가 · 보스 피해 감소 · 경험치 · 골드 각 3.5%, 5인 각 5%
  • ⚠️ 파티 안 최고 · 최저 레벨 차이가 10 이상이면 파티 효과(경험치 · 골드 증가, 보스 피해 증가 · 받는 피해 감소)와 차원 동행이 전부 꺼져요. 한 명만 차이 나도, 멀리 떨어져 있어도 똑같이 판정
  • 몬스터 처치 퀘스트는 파티원이 잡은 것도 인정, 이동 · 상호작용 퀘스트는 각자 해야 해요

몬스터 도감

  • 메뉴 → [몬스터 도감]: [월드] 윈스톤 · 레이단 · 레베카 영지(지역 13곳) · [던전] 골렘의 미궁 · 야탄 신전
  • 몬스터 카드마다 별 5개. 일반 몬스터는 지역 「○○형 데이터」 5개, 보스는 전용 재료 1개로 등록
  • 등록 보상: 골드 · 일반 제작 재료 확정 상자 등. 지역 별이 5개 쌓일 때마다 달성 효과(경험치 · 골드 · 방어력 등) — 노튼은 첫 단계가 경험치 획득량 1%
  • 지역별 보스 26종 · 출현 위치 · 등록 재료는 레벨별 사냥터 → 몬스터 도감

창고 · 우편함

  • 창고는 2종류: 개인 창고(그 캐릭터만, 귀속 아이템만) / 공용 창고(같은 계정 · 같은 서버 캐릭터끼리, 비귀속만). 마을 창고 관리인 NPC
  • [자동 보관]: 창고에 이미 있는 물약 · 재료와 같은 것을 버튼 하나로 정리. 물약은 소지 한도까지만 꺼낼 수 있어요
  • 우편함은 계정 · 캐릭터 · 편지 3칸, 각각 최대 100개(화면엔 「받은 우편 n/300」). 넘치면 새 우편이 안 보일 수 있으니 정리하세요
  • ⚠️ 계정 우편은 전체 서버에서 딱 1번만 받을 수 있어요. 사전등록 보상 같은 건 키울 서버 · 캐릭터로 접속해서 받기. [모두 받기] 때 계정 우편은 빼고 받을 수도 있음
  • 편지는 다른 서버 플레이어 · 길드에게도 보낼 수 있어요(비용 · 하루 횟수 제한)
  • 보관 기간이 지나면 보상째 삭제, 인벤토리가 꽉 차면 못 받아요

던전 입장 · 이용 시간

  • 메뉴 → [던전]: 던전마다 입장 레벨 · 퀘스트 조건 · 필요 재화가 달라요. 조건이 안 되면 잠금 표시
  • 목록의 표시: 안전(PvP 불가) · 일반(선택) · 위험(PvP 가능)
  • 이용 시간 = 기본 시간(초기화 때 다시 채워짐) + 충전 시간(던전별 시간 충전석으로 충전, 초기화돼도 남음). 기본 시간부터 먼저 깎여요
  • 안에 있는 동안은 싸우지 않아도 시간이 줄어요. 다 쓰면 자동 퇴장
  • [퇴장] 버튼은 들어오기 전 필드 자리로, 귀환 주문서는 마을로. 일정이 정해진 던전은 시간이 남아도 끝나면 퇴장

퀘스트 규칙

  • 메인(스토리 · 새 지역) · 서브(시스템 안내) · 히든(조건 · 힌트 발견) 3종
  • 일부 퀘스트는 동시에 진행할 수 있는 개수가 정해져 있어요. 꽉 차면 끝내거나 포기하고 받기
  • 서브 · 히든은 포기 후 다시 받기 가능(진행도 초기화). 메인은 포기 불가
  • 목표가 안 올라가면 지금 있는 차원을 확인 — 퀘스트마다 진행 가능한 차원이 달라요
  • 일부 보상은 계정당 1번. 인벤토리가 꽉 차면 보상 수령이 막혀요
  • 반복 히든 퀘스트는 목록에 「반복」 표시, 초기화되면 진행도도 처음부터

캐릭터 정보 · 스탯 · 속도 한계

  • 메뉴 → [캐릭터 정보]: 정보 · 스탯 · 각성 3탭. HP/MP 표시를 눌러도 열려요
  • 남은 스탯 포인트는 [스탯] 탭에서 분배 → [결정]. 되돌리려면 스탯 초기화 주문서 필요
  • 엘릭서를 쓰면 스탯 포인트가 생겨요. 엘릭서 사용 한도와 스탯별 투자 한도는 따로 있어요
  • 속도 한계: 공격 속도는 기본 평타 기준 최대 260%, 시전 속도는 스킬마다 따로 상한. 동작이 최소 시간에 닿으면 속도를 더 올려도 안 빨라져요
  • 이동 속도는 최대 100%, 지상 · 비행 펫을 타면 최대 150%
  • [각성] 탭: 단계마다 필요 레벨 · 이전 각성 · 재료가 있고, 능력치 · 칭호 · 아이템을 줘요

채광 (곡괭이)

  • 곡괭이를 전용 슬롯에 장착(손상 안 된 것). 광물은 캐릭터당 한 번만, 시작 전에 인벤토리 빈칸 1칸 이상
  • 광물 2종류: 기여도 조건(그 몬스터에 기여도가 있어야 캠) / 제한 없음. 일부는 시간이 지나면 사라져요
  • 보상은 일반 · 상급. 상급 확률은 곡괭이 능력치 · 손재주로 오르고, 채광 추가 보상 확률은 받는 수량을 늘려요(둘은 따로 계산)
  • 다른 플레이어에게 맞으면 채광이 끊겨요(몬스터 공격은 안 끊김). 채광 방해 저항으로 막을 수 있지만 스턴 같은 상태 이상은 무조건 끊김
  • 다른 차원에서 캐면 같은 광물이라도 다른 보상(추가가 아니라 별도 보상표). 곡괭이 강화는 전용 강화석

랭킹 4종 · 보상

  • 차원 · 레벨 · PvP · 길드 4가지, 서버 단위. 메뉴 → [랭킹]
  • 차원: 차원 공헌도 기준, 새 시즌에 초기화 → 구간별 작위
  • 레벨: 누적 경험치, 초기화 없음 → 매주 월요일 오전 5시 순위로 칭호 · 패시브 적용
  • PvP: PvP 점수, 매주 월요일 오전 5시 초기화 → 칭호 · 패시브. 분쟁 지역은 서로 싸운 경우만 집계
  • 길드: 주간 활동 포인트, 매주 월요일 오전 5시 초기화 → 거래소 판매 세금 감면
  • 혜택은 자동 적용(미접속이면 다음 접속 때). 다른 차원에 가 있으면 내 순위가 안 보여요 — 소속 차원으로 돌아와서 확인

PvP · 악명 · 수배

  • 보호 · 안전 · 평화 지역: PvP 불가 / 일반 지역: 조건부 PvP, 처치하면 악명 증가 / 분쟁 지역(필드 보스 구역 등): 자유 PvP, 악명 없음
  • 먼저 때리면 약탈자(이름 색 바뀜). 맞은 쪽은 정당방위로 반격해도 악명이 안 올라요. 서로 적대한 길드원 처치도 악명 없음(일방 적대는 해당 없음)
  • 다른 차원 사람끼리는 일반 지역 PvP 불가, 분쟁 지역에서만 가능
  • 악명은 내 레벨 ±5 몬스터 사냥이나 접속 시간으로 줄어요(접속 안 하면 안 줄어요)
  • 단계: 감시 대상 1 · 2 → 수배범(던전 · 텔레포트 · 스케줄 모드 · 채팅 필터 제한, 잡화점 추가 비용) → 무법자(귀환 · 친구 제한) → 학살자(이벤트 보상 수령 제한). 모든 단계 능력치 감소
  • 경계 대상으로 등록하면 같은 채널에서 다가올 때 알림 · 미니맵 표시. 수배범은 악인 수배 목록에 위치까지 떠요

미션 (일일 · 주간 · 차원)

  • 메뉴 → [미션]: 일일(지역 골라서) · 주간 · 차원(다른 차원에서만 수행)
  • 일일은 매일, 주간 · 차원은 매주 초기화. 초기화 전에 수락한 미션은 넘어가서 완료해도 새 횟수에서 안 빠져요 → 초기화 직전에 수락해 두면 이득
  • 일일 미션은 [미션 갱신](비용)으로 목록을 바꿀 수 있지만 남은 완료 횟수는 그대로. 횟수는 미션 횟수 추가권으로만 늘어요
  • 완료 대기 미션은 한 번에 완료 가능 — 인벤토리 칸이 모자라면 완료가 막히니 미리 비우기

상인 NPC · 일괄 구매

  • 일괄 구매 설정에 아이템별 목표 보유 수량을 저장 → [일괄 구매]를 누르면 모자란 만큼만 사요 (예: 목표 100, 보유 30 → 70개 구매)
  • 물약은 일괄 구매 때 회복량 높은 물약부터 사요
  • 구매 제한이 공유되는 상품은 같은 서버 다른 캐릭터 구매량도 합산
  • 여러 개 선택 판매는 중첩 아이템을 전부 팔아요 — 일부만 팔려면 개별 판매. 되사기 없음

무기 개조

  • 날 · 손잡이 · 키링을 갈아 끼워 외형과 성능 방향을 바꿈
  • 콘텐츠마다 맞는 무기가 다름: 보스는 치명타·피해 배율, 높은 사냥터는 명중, PvP는 상대를 묶는 효과
  • 그래서 무기 하나가 아니라 용도별로 여러 개를 준비하는 게 핵심
  • 개조에도 파브라늄이 들어감

대장장이 등급 · 제작

  • 시작 등급 견습 대장장이, 제작할 때마다 제작 경험치가 쌓이고 도안이 있어야 만들 수 있음
  • 실측 예: 에픽 활 「정교한 불꽃의 활(귀속)」 = 망가진 지슈카의 활 + 대장장이 망치, 캐릭터당 1회. Lv.80부터 착용, 무기 공격력 16~59 · 스킬 공격력 4 · 원거리 명중 9
  • 제작 화면에서 결과물 성능을 미리 보기로 확인할 수 있으니 재료 쓰기 전에 꼭 확인
  • 제작을 반복하면 대장장이 등급이 오름
  • 명장 등급 이상부터 제작 대성공 가능
  • 대성공하면 내 이름이 새겨진 시그니처 장비 → 다른 이용자가 쓰는 장비가 될 수 있음

템빨 코인 · 왕실 무기고

  • 안 쓰는 장비를 왕실 무기고에 납품하면 템빨 코인으로 교환
  • 강화가 높은 장비일수록 코인을 많이 받음
  • 오염된 존재, 인마대전, 히든 퀘스트, 차원 콘텐츠에서도 획득
  • 전용 상점에서 성장 재료·상위 장비로 교환

무료 편의 기능

  • 스마트 파티: 파티 모집과 합류를 도와줌
  • 스케줄 모드: 일일 미션, 시간제 던전, 사냥터를 정해 둔 일정대로 진행
  • 둘 다 과금과 상관없이 모두 무료

협력 콘텐츠

  • 필드 엘리트 몬스터 오염된 존재
  • 인마대전: 서버 전체가 마물 공세를 막고 바알의 사념체 공략
  • 헬가오 레이드: 코크로 섬
  • 보상 템빨 코인: 상위 장비 도전, 펫, 차원 유물 구매

월드맵 · 기억 텔레포트

  • 미니맵 클릭 또는 M키. 마을 = NPC, 사냥터 = 전리품 · 몬스터, 거점 = 골드 내고 즉시 이동, 필드 보스 = 지금 위치와 보상
  • 목적지를 누르고 [이동](자동 이동) 또는 [텔레포트](골드)
  • 자주 가는 지역은 즐겨찾기 별표로 모아 두기
  • [기억] 탭: 지금 위치를 저장해 두고 기억 주문서 1개로 그 자리로 텔레포트. 최대 25곳
  • 지도에서 위치를 눌러 [공유]하면 채팅에 위치 링크가 올라가요 → 파티원 모을 때 편해요

인벤토리 · 분해

  • 탭: 전체 · 장비 · 소모품 · 재료 · 자동 사용. 조건이 안 맞는 아이템은 붉게 표시
  • 아이템을 고른 뒤 화면 아래 퀵슬롯을 누르면 등록(이미 있는 칸은 덮어쓰기)
  • 칸이 모자라면 사냥 보상 · 우편 수령이 막힐 수 있어요. 확장권은 상점, 최대 한도 있음
  • [분해]: 일괄 선택 때 등급 · 강화 장비 · 거래 가능 · 수집 등록 가능 장비 포함 여부를 고를 수 있어요. 수집에 쓸 장비는 꼭 빼기
  • 장착 중 · 잠금 장비는 분해 안 됨, 분해는 되돌릴 수 없음. 확정 재료 + 확률 추가 재료

절전 모드

  • 화면 왼쪽 아래 [절전 모드]. 자동 전투를 먼저 켜고 들어가야 계속 사냥해요
  • 절전 중에도 경험치 · 골드 · 획득 아이템 · 인벤토리 칸 · 물약 남은 수 · 시간제 지역 남은 시간이 보여요
  • 채팅 보기 · 보내기는 돼요. 파티 · 공격대 참여는 해제 후
  • [환경설정] → 절전 모드 전환 시간: 조작이 없으면 자동 전환(모바일 자동 전환 오류는 확인 중)
  • 해제: 로고를 밀기 · PC는 ESC. 다른 플레이어와 싸우거나 죽으면 자동 해제

채팅 · 친구

  • 탭: 전체 · 서버 · 지역 · 귓속말 · 길드 · 파티 · 공격대 · 시스템. 한 번에 최대 60자, PC는 Enter 전송 · Tab으로 종류 변경
  • 아이템 · 클래스 · 펫 정보의 [공유] → 채팅에 링크(메시지당 1개)
  • 같은 말을 반복하면 잠시 채팅이 막혀요. 보기 싫은 사람은 이름 눌러 채팅 차단(내 화면에서만 숨김)
  • PC는 설정 → 게임 → 화면 표시에서 채팅창을 새 창으로 분리 가능
  • 친구 요청은 상대의 소속 서버를 고르고 이름 입력(지금 머무는 차원 아님). 접속하면 알림 + 인사말 보내기. 요청이 귀찮으면 환경설정 → 알림 → 친구 신청 자동 거절
